# Abhishek Patnaik Premium CV Website

A premium, interactive static CV website built with HTML, CSS and JavaScript. No build tools or paid hosting required.

## Files
- `index.html` - Website structure and CV content
- `styles.css` - Premium UI styling, responsive layout and animations
- `script.js` - Interactions, counters, scroll reveal, mobile menu and copy email

## Quick GitHub Pages Hosting
1. Create a GitHub repository named `abhishek-cv-website` or `yourusername.github.io`.
2. Upload `index.html`, `styles.css`, `script.js` and this README to the repository root.
3. Go to repository **Settings > Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/root`, then save.
6. Your website will go live at `https://yourusername.github.io/abhishek-cv-website/` or `https://yourusername.github.io/` if you use the special username repository.
